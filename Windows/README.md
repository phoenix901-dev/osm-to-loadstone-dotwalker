# Windows-сборка (без Python)

Готовая сборка конвертера для Windows 10/11. Ничего устанавливать не нужно:
Python не требуется, всё работает встроенными средствами Windows.

## Как пользоваться

Все действия — в одной папке конвертера (`Windows/`).

1. **Запусти `get_osm.cmd`.** Он спросит название населённого пункта —
   напиши, например, `Москва`, и нажми Enter. Программа сама найдёт границы,
   скачает свежую карту OpenStreetMap и сохранит её в папку `In`.
   Если данные большие — загрузка сама разделит их на части, а потом склеит.
   Дождись надписи, что всё готово.

   Если название не находится, можно задать область вручную четырьмя числами
   через точку: `get_osm.cmd долгота1 широта1 долгота2 широта2`.

2. **Запусти `convert.cmd`.** Он сконвертирует скачанную карту в файлы
   навигации. Дождись окончания.

3. **В папке `Out/`** появятся три файла:
   - `loadstone.txt` — база точек для LoadStone;
   - `route.xml` — объекты: магазины, остановки, организации и прочее;
   - `route.dat` — маршрутные точки для DotWalker, с типами: адреса домов
     (`residence`), переходы и светофоры (`path`), перекрёстки улиц
     (`intersection`), остановки и ж/д (`transport`), а также направления улиц.

4. Скопируй эти три файла на телефон и загрузи их в LoadStone и DotWalker
   тем же способом, что и раньше.

## Замечания

- Первая загрузка города занимает несколько минут. Пока в папке `In` лежит
  файл `data.osm`, можно запускать `convert.cmd` заново без повторной загрузки
  (например, если поправил слова-замены).
- **Слова-замены** — в папке `conv/` файл `ReplaceListWord.txt`. Первое слово —
  что заменять, второе — чем заменять, между ними знак равенства. Например,
  строка `супермаркет=магазин` заменит все слова «супермаркет» на «магазин».
  После правки конвертацию надо запускать заново. Будь осторожен при
  редактировании: лучше заранее сделать копию файла.
