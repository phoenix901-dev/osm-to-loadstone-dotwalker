# OSM → LoadStone + DotWalker

Конвертер карт [OpenStreetMap](https://www.openstreetmap.org) в базы точек для
слепых и слабовидящих пользователей навигационных программ
**LoadStone** и **DotWalker**.

Одна команда превращает название города в готовые файлы навигации: точки с
названиями, улицы, остановки, переходы, перекрёстки и адреса домов.

## Что на выходе

После конвертации в папке `Out/` появляются три файла:

| Файл | Программа | Описание |
|------|-----------|----------|
| `loadstone.txt` | LoadStone | база точек с названиями |
| `route.xml` | DotWalker | объекты: магазины, остановки, организации |
| `route.dat` | DotWalker | маршрутные точки с типами: `residence` (адреса домов), `path` (переходы, светофоры), `intersection` (перекрёстки), `transport` (остановки, ж/д), а также направления улиц |

## Платформы

Проект содержит две независимые сборки:

- [**Linux**](#линукс) — чистый Python 3, ничего устанавливать не нужно,
  кроме самого Python (обычно уже есть).
- [**Windows**](#windows) — готовая сборка без Python, всё работает
  встроенными средствами Windows 10/11.

## Линукс

Требуется `python3` (проверь: `python3 --version`) и интернет.

```bash
python3 osm2nav.py "Новороссийск"
```

Город с запасом вокруг административной границы (радиус в км):

```bash
python3 osm2nav.py "Санкт-Петербург" 5
```

Или вручную четыре числа через точку — `minlon minlat maxlon maxlat`:

```bash
python3 osm2nav.py 38.43 55.84 38.47 55.86
```

Скрипт сам геокодирует название, скачивает карту через Overpass (если кусок
велик — дробит на части, при занятом сервере ждёт и пробует зеркала) и
конвертирует. В конце печатает, куда положил файлы и сколько точек получилось.

Компоненты можно запускать по отдельности:

```bash
python3 get_osm.py "Новороссийск"     # только закачка карты → In/data.osm
python3 convert.py In/data.osm        # конвертация → Out/
python3 enrich.py                     # типизация route.dat (ENRICH v2)
```

Замены выражений редактируются в `ReplaceListWord.txt` (например,
`супермаркет=магазин`). После правки перезапусти `convert.py`.

## Windows

В папке [`Windows/`](Windows/) — готовая сборка, Python и зависимости не нужны.

1. Запусти `get_osm.cmd` — введи название населённого пункта, программа скачает
   свежую карту в `In/`.
2. Запусти `convert.cmd` — конвертация в `Out/`.
3. Скопируй три файла из `Out/` на телефон и загрузи в LoadStone / DotWalker.

Подробности — в [`Windows/README.md`](Windows/README.md).

## Замечания

- Промежуточная карта лежит в `In/data.osm`; свежие прогоны её перезаписывают.
- При повторном прогоне той же области точки получают те же id — база не
  «мусорит» дубликатами при обновлении.
- Режим строгого соответствия старой Windows-сборке (для проверки):
  `python3 convert.py --faithful In/data.osm`.
